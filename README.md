Student Performance Data Analysis

Project Objective

To analyze student scores in Math, Reading, and Writing using Python and data visualization.

Dataset Description

The dataset contains student information, parental education, test preparation status, and subject scores.

Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

Data Analysis

- Inspected and cleaned the dataset.
- Analyzed student scores using Pandas.
- Compared scores across test preparation and parental education categories.

Key Findings

- Students who completed test preparation had higher average scores across all three subjects.
- The largest score difference was observed in Writing.
- Students whose parents had a master's degree showed higher average scores than those whose parents had a high school education.

Conclusion

This project explored student performance and identified patterns in subject scores using Python and data analysis techniques.
